# Site ECP Builder

Build a two-page site Environmental Control Plan in the browser: find the site on an aerial map, draw the boundary, mark locations of interest (spill kits, drains, stockpiles, sensitive receivers and more), tick site activities, review the controls the tool selects, and print to PDF (A3 or A4 landscape).

Live at **https://ecp.oenvc.com/** · part of [OENVC](https://www.oenvc.com/).

- Single static `index.html` (Leaflet 1.9.4 from cdnjs)
- Imagery: Esri World Imagery; streets: OpenStreetMap; search: OpenStreetMap Nominatim
- Plans are saved in the browser and can be exported/imported as a JSON plan file
